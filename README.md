
# 💰 Expense Tracker

A simple and responsive web-based Expense Tracker application built using HTML, CSS, and JavaScript.
It helps users record daily expenses, track spending, and manage their financial activities efficiently.

---

## 🚀 Live Demo

Website url: https://rohit9371.github.io/Expense-tracker/

---

## 🛠️ Tech Stack

* **HTML5** — Structure
* **CSS3** — Styling & Responsive Design
* **JavaScript (ES6)** — Logic & Functionality
* **LocalStorage** — Data persistence

---

## ✨ Features

* ➕ Add income & expense transactions
* 🗑️ Delete transactions
* 💰 Real-time balance calculation
* 📊 Income vs Expense summary
* 🗂️ Transaction history list
* 💾 Data stored in browser (LocalStorage)
* 📱 Fully responsive UI
